1. Executive Summary

The Task Management Application is a fast, responsive, single-page web app designed to let authenticated users create, view, and track personal tasks in real time. It utilizes a zero-build architecture with standard HTML5, CSS3, and JavaScript ES modules to ensure maximum reliability and fast loading speeds.

2. Core Application Features

  • Google Authentication: Secure sign-in powered by Firebase Google OAuth 2.0.
  • Task Creation: Allows adding tasks with mandatory title and optional description.
  • Real-Time Task View: Displays tasks belonging strictly to the current user, updating automatically via Cloud Firestore listeners.
  • Task Status Management: Supports exactly three task statuses: Planned, In Progress, and Complete.
  • Status Filter Tabs: Filter task lists instantly by tab selection.

3. Technical Architecture

Layer Technology Selected Rationale & Benefit
Frontend HTML5 & CSS3 (Vanilla) Zero build tool errors, fast execution, responsive UI cards.
Logic & SDK JavaScript (ES Modules) Direct CDN module imports from official Firebase JS SDK v10.
Authentication Firebase Auth (Google OAuth) Secure Google login handling with session tracking.
Database Cloud Firestore NoSQL real-time cloud data storage (`onSnapshot`).
Hosting Firebase Hosting Global CDN static hosting with SSL security.

4. Task Status Lifecycle

Status State Trigger Description
Planned Default Automatically assigned when a new task is created.
In Progress User Action Selected when active work starts on a task.
Complete User Action Selected when a task is completed. Badge turns green.

5. Security & Data Privacy Rules

  • User Data Binding: Tasks are created with userId: currentUser.uid.
  • Data Query Isolation: Firestore queries fetch documents matching where("userId", "==", currentUser.uid).
  • Security Rules: Firestore security rules strictly allow read and write operations to authenticated users.

6. Support & Error Handling Matrix

Error Condition Handling Mechanism
Popup Closed / Interrupted Displays error banner instructing user to click once and allow popups.
Double Click Prevention Disables login button during active login request.
Empty Task Input Form validation blocks submission and prompts user for title.
Firestore Permission Error Displays diagnostic message requesting rule update in Firebase Console.
